# Tools and Templates Reference

## Free Tools

| Tool | Use in Course |
| --- | --- |
| Paper and sticky notes | Process sketches, brainstorming, waste walk notes. |
| Whiteboard | Group discussion and simple mapping. |
| Microsoft Excel | Check sheets, tally tables, and simple charts. |
| LibreOffice Calc | Spreadsheet alternative for basic charts. |
| Google Sheets | Shared check sheets and team data collection. |
| diagrams.net | Simple SIPOC and process maps. |

## Core Templates

| Template | Key Fields |
| --- | --- |
| Customer Value Worksheet | Customer, need, output, value statement |
| SIPOC | Suppliers, inputs, process, outputs, customers |
| Process Map | Step, owner, handoff, wait, problem note |
| TIMWOODS Waste Table | Waste type, observed example, process step, impact |
| Check Sheet | Category, tally, total, notes |
| 5 Whys | Problem, why chain, possible cause, evidence needed |
| Fishbone | People, process, tools, materials, measurement, environment |
| 5S Action List | Sort, set in order, shine, standardize, sustain |
| Standard Work | Task, steps, expected result, check method |
| Action Plan | Improvement idea, owner, due date, support needed, measure |

## Simple Formulas

```text
Total Count = Sum of all tallies
Percent of Total = Category Count / Total Count
Before-After Change = After Value - Before Value
Percent Change = (After Value - Before Value) / Before Value
```

## Chart Selection Guide

| Need | Suggested Visual |
| --- | --- |
| Show process steps | Simple flowchart |
| Show who receives what | SIPOC |
| Count problem categories | Bar chart |
| Find biggest category | Pareto-style sorted bar chart |
| Show change over time | Run chart |
| Show possible causes | Fishbone diagram |
