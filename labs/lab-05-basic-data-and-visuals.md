# Lab 05 - Basic Data and Visuals

## Objectives

- Create a basic check sheet.
- Count issue categories.
- Build a simple visual.
- Use data to focus discussion.

## Scenario

Improvement should not rely only on opinion. You will collect a small amount of simple data and use it to identify what to discuss first.

## Steps

1. Choose one issue or waste area from Lab 04.
2. Decide what can be counted safely.
3. Define clear categories.
4. Create a check sheet with category names and tally marks.
5. Collect sample data or use a trainer-provided dataset.
6. Add the tally marks.
7. Calculate category totals.
8. Calculate total observations.
9. Create a bar chart.
10. Sort the chart from largest category to smallest category.
11. Create a run chart if the data includes dates or times.
12. Write one sentence explaining what the visual shows.
13. Write one question that should be investigated.

## Validation

- Categories are clear and not overlapping.
- Counts are added correctly.
- The chart has a title and labels.
- The conclusion is based on the data shown.

## Deliverables

- Check sheet.
- Tally table.
- Bar chart or Pareto-style chart.
- Run chart if time data is available.
- Data observation note.

## Review Questions

1. Why is a check sheet useful?
2. Why should categories be clearly defined?
3. What does a sorted bar chart help you see?
4. How can simple data improve team discussion?
