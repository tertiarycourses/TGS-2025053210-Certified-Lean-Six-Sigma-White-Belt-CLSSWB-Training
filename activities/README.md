# Certified Lean Six Sigma White Belt (CLSSWB) Training — Activities

**WSQ Course Code:** TGS-2025053210  |  **Version v5 · 23 September 2026**

5 hands-on activities — exactly one per phase of the **DMAIC roadmap**. Every activity runs on one continuous scenario, the **BrewBean Cafe morning rush**, and each activity's output becomes the next one's input, so by the end of the day your work forms a single complete improvement package.

## What each activity folder contains

| Artefact | What it is | Who uses it |
|---|---|---|
| `ANN-Facilitator-Guide-*.docx` / `.pdf` | Purpose, materials, set-up, scenario, the numbered run-sheet with facilitator notes, timing, debrief and success criterion | Trainer |
| `ANN-Learner-Worksheet-*.docx` / `.pdf` | The scenario, the steps, and a working space to capture the output and prompt answers | Learner |
| `ANN-Checklist-*.docx` / `.pdf` | Criteria table to tick before the debrief, plus feedback | Learner group |
| `data/` | The mock datasets as `.csv`, plus one `.xlsx` workbook holding every dataset and template on its own tab, and a data dictionary | Learner |
| `templates/` | Blank worksheets to fill in, as `.csv` | Learner |
| `model-answer.md` | The worked model answer — read it *after* attempting the activity | Learner |

> The **detailed step-by-step instructions live here and in the Learner Guide — never on the slides.** The trainer facilitates the scenario and discussion from the deck while learners work from these sheets and the data.

## About the data

Every figure is **mock data** built for training. It is internally consistent across all five activities:

- The Activity 2 observation log is the evidence base for the Activity 3 Pareto.
- The Activity 3 root cause is what the Activity 4 countermeasure addresses.
- The Activity 4 pilot results carry into the Activity 5 monitoring data.

So the numbers you quote in one activity still hold in the next, and the whole BrewBean Cafe story reconciles from Define through to Control.
